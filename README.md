# 찰칵 (chalkak)

Windows용 화면 캡쳐 도구입니다. 찍은 화면에 바로 표시를 그려 넣고, 이전 캡쳐와 복사했던 텍스트를 다시 꺼내 쓸 수 있습니다. AI 에이전트에게 화면을 보여 주는 작업에 맞춰 만들었습니다.

- 단축키로 영역을 드래그해 캡쳐 → 클립보드 복사와 파일 저장이 한 번에
- 캡쳐 히스토리: 이전 캡쳐를 골라 이미지나 파일 경로로 다시 복사
- 편집기: 사각형, 밑줄, 화살표, 번호 표시(①②③), 텍스트
- 캡쳐를 화면 위에 띄워 두기
- 이미지에서 글자 추출 (Windows 내장 OCR)
- 복사한 텍스트 히스토리
- 명령줄 도구: 스크립트나 AI 에이전트가 직접 캡쳐 실행

## 설치

Windows 10/11 (64비트)에서 동작합니다. 별도로 설치할 프로그램은 없습니다.

1. [최신 릴리스](https://github.com/kimjkeun/chalkak/releases/latest)에서 `chalkak-…-windows-x64.zip`을 받아 압축을 풉니다.
2. 압축을 푼 폴더에서 PowerShell을 열고 실행합니다.

   ```
   .\chalkak.exe install
   ```

   `%LOCALAPPDATA%\chalkak\bin`에 복사되고 트레이 프로그램이 바로 실행됩니다.
3. 부팅할 때 자동으로 실행하려면 트레이 아이콘을 오른쪽 클릭해 **Windows 시작 시 자동 실행**을 체크합니다.

설치하지 않고 `chalkak_tray.exe`를 더블클릭해 바로 써도 됩니다.

### 실행이 막힐 때

서명되지 않은 프로그램이라 처음 실행할 때 Windows가 경고할 수 있습니다.

- **"Windows의 PC 보호" 창**: **추가 정보 → 실행**을 누릅니다.
- **스마트 앱 컨트롤**이 켜져 있으면 실행 자체가 차단됩니다. Windows 보안 → 앱 및 브라우저 컨트롤에서 끄지 않는 한 사용할 수 없습니다.

## 단축키

| 단축키 | 동작 |
|---|---|
| `Ctrl+Alt+A` | 영역 캡쳐 (드래그로 선택, `Esc`나 오른쪽 클릭으로 취소) |
| `Ctrl+Alt+S` | 직전에 선택한 영역을 그대로 다시 캡쳐 |
| `Ctrl+Alt+E` | 영역 캡쳐 후 바로 편집기 열기 |
| `Ctrl+Alt+D` | 캡쳐 히스토리 (편집기) |
| `Ctrl+Alt+Q` | 복사한 텍스트 히스토리 |

트레이 아이콘을 왼쪽 클릭하면 영역 캡쳐, 오른쪽 클릭하면 메뉴가 열립니다.

캡쳐는 `사진\Captures` 폴더에 `capture_날짜_시간.png`로 저장되고, 가장 최근 것은 `latest.png`로도 남습니다.

## 편집기

`Ctrl+Alt+D`로 엽니다. 왼쪽에 큰 미리보기, 오른쪽에 캡쳐 목록이 있습니다.

| 키 | 동작 |
|---|---|
| `R` / `U` / `A` | 사각형 / 밑줄 / 화살표 (드래그) |
| `N` | 번호 표시 (클릭할 때마다 1, 2, 3…) |
| `T` | 텍스트 (클릭한 자리에 입력, `Enter`로 확정) |
| `Ctrl+Z` | 마지막에 그린 것 되돌리기 |
| `Enter` / `Shift+Enter` | 이미지로 복사 / 파일 경로로 복사 |
| 숫자 `1`~`9`, 목록 더블클릭 | 그 캡쳐를 바로 복사 |
| `O` | 글자 추출해서 복사 |
| `P` | 캡쳐를 화면 위에 띄우기 |
| `Delete`, 목록의 × | 휴지통으로 보내기 |
| `Esc` | 닫기 |

그림을 그린 뒤 복사하면 새 파일로 저장되고 원본은 그대로 남습니다.

띄운 캡쳐는 안쪽을 끌어 옮기고, 가장자리를 끌거나 휠을 돌려 크기를 바꾸고, 오른쪽 클릭이나 `Esc`로 닫습니다.

## 복사한 텍스트 히스토리

텍스트를 복사할 때마다 기억해 두었다가, `Ctrl+Alt+Q`로 목록을 띄워 고르면 쓰던 창에 바로 붙여 넣습니다. 클릭, 숫자 키, 방향키와 `Enter`로 고릅니다.

메모리에만 보관하므로 프로그램을 끄면 사라집니다. 비밀번호 관리자가 기록하지 말라고 표시한 내용은 기억하지 않습니다.

## 설정

트레이 메뉴의 **설정 파일 열기**로 `%APPDATA%\chalkak\config\config.toml`을 고치고, **설정 다시 불러오기**를 누르면 적용됩니다.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `save_dir` | 비어 있음 (`사진\Captures`) | 저장 폴더 |
| `copy` | `"image"` | 캡쳐 직후 클립보드에 올릴 것: `image`, `path`, `none` |
| `sound` | `true` | 캡쳐할 때 "찰칵" 효과음을 낼지 |
| `history_size` | `20` | 편집기 목록에 보일 캡쳐 수 |
| `history_layout` | `"right"` | 캡쳐 목록 위치: `right`, `top` |
| `text_history_size` | `30` | 기억할 복사 텍스트 수 |
| `[hotkeys]` | 위 표 참고 | 전역 단축키. 비우면 사용하지 않음 |

## 명령줄

```
chalkak region [옵션]      드래그로 영역을 선택해 캡쳐
chalkak again [옵션]       직전에 선택한 영역을 다시 캡쳐
chalkak full [옵션]        주 모니터 전체를 캡쳐
chalkak ocr <이미지 파일>   이미지의 글자를 읽어 출력
chalkak monitors           연결된 모니터 목록
chalkak autostart <on|off|status>
chalkak config             설정 파일 위치
chalkak install            고정 위치에 설치하고 트레이 프로그램 실행

옵션:
  --out <파일>              저장할 파일 (png, jpg)
  --copy <image|path|none>  클립보드에 올릴 것
```

저장된 파일의 경로를 표준 출력에 씁니다. AI 에이전트가 `chalkak again --copy none`으로 같은 영역을 다시 찍어 결과를 직접 확인하게 할 수 있습니다.

## 직접 빌드하기

[Rust](https://rustup.rs)와 Visual Studio Build Tools(C++ 워크로드)가 필요합니다.

```
cargo build --release
.\target\release\chalkak.exe install
```

## 알아둘 점

- 글자 추출은 Windows에 설치된 인식 언어를 씁니다. 한국어 인식기만 있는 PC에서는 영문과 기호의 정확도가 떨어집니다.
- 관리자 권한으로 실행된 프로그램에는 텍스트 히스토리의 자동 붙여넣기가 되지 않을 수 있습니다. 이때도 클립보드에는 올라가 있으므로 `Ctrl+V`로 붙이면 됩니다.
